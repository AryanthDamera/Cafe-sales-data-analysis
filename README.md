# Cafe Sales Data Analysis

## Overview
This is my first Data Analysis project using a cafe sales dataset from Kaggle. The dataset contains messy and inconsistent data, which helped me improve my data cleaning and preprocessing skills.

In this project, I performed:

- Data Cleaning  
- Data Transformation  
- Feature Engineering  
- Exploratory Data Analysis 
- Data Visualization  

The main goal of this project is to analyze cafe sales data and extract meaningful business insights from the dataset.

---

## Dataset Columns

- Transaction_ID  
- Item  
- Quantity  
- Price_Per_Unit  
- Total_Spent  
- Payment_Method  
- Location  
- Transaction_Date  

---

## Data Cleaning Process

Some of the cleaning steps performed in this project:

- Handling missing values  
- Removing duplicate records  
- Object-to-numeric conversion  
- Filling null values  
- Fixing inconsistent values  
- Filling Total_Spent using Quantity × Price_Per_Unit  
- Handling unknown values in Payment_Method  
- Outlier checking  
- Feature Engineering  
- Creating a Day column for weekly analysis  

---

## Questions Solved

1. Highest revenue-generating item  
2. Most sold item  
3. Least sales month  
4. Highest total spent  
5. Customer takeaway preference analysis  

---

## Key Insights

- Salad is the highest revenue-generating item  
- Juice is the most sold item  
- February is the least sales month  
- Around 69% of customers preferred takeaway orders
